# Objectives

## Main objective

Develop and validate a machine-learning decision-support prototype for ship total fuel-flow prediction and supported voyage-speed comparison using real public operational data.

## Specific objectives

1. Verify FuelCast provenance, units, licence and data quality for CPS Triton.
2. Build leakage-aware features and chronological partitions with temporal embargoes.
3. Compare a cubic speed baseline, Random Forest and XGBoost using MAE, RMSE and R².
4. Quantify predictive improvement from environmental context on a held-out future block.
5. Implement a transparent, time-constrained speed grid with empirical support checks and correct units.
6. Identify unreliable operating regions and communicate assumptions in a reproducible Streamlit dashboard.
